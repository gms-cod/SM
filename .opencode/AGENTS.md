# Правила работы

## Запуск процессов
- GUI-приложения запускай через субагентов (Task tool), чтобы не вешал основной агент
- В субагенте: запустил → подождал N секунд → проверил жив ли → убил `Stop-Process -Force`
- Таймауты: максимум 30с на ожидание
- Обязательно убивай процесс после проверки (даже если жив)
- Проверяй `$proc.HasExited` и читай stderr если завершился с ошибкой

## Логирование
- Записывай stdout/stderr процессов во временные файлы
- После завершения процесса показывай последние строки лога
- Для GUI: процесс жив → окно открыто и не упало

## Тестирование
- Пиши тесты для новой функциональности
- Запускай `dotnet test` и проверяй результат
- Тесты должны быть изолированными (не зависеть от внешних процессов)

## Сборка
- После изменений всегда пересобирай проект
- Проверяй ошибки сборки
- Убедись что файлы публикуются в SMon\
