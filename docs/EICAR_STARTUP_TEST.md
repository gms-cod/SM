# Проверка EICAR и автозагрузки

6 ноября 2026 года проверена установленная локальная сборка Startup Monitor 2.1.1. Использован безопасный стандартный тест EICAR с официального `https://secure.eicar.org/eicar.com.txt`. Реальные вредоносные программы не использовались.

Файл загружен успешно: **68 байт**, SHA-256 `275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f`. Проверялись размер и контрольная сумма до записи на диск. Создано одно уникальное значение HKLM Run, указывающее на файл в собственном временном каталоге. Файл не исполнялся, вход в систему и перезагрузка не вызывались, настройки защиты не менялись.

Результат текущей политики **AutoGuard AuditOnly**, мониторинг включён, правило временных каталогов включено:

- Startup Monitor примерно за две секунды обнаружил запись и сохранил события `PolicyWarning` и `Added`. Причина предупреждения — автозапуск из ненадёжного временного каталога.
- Значение Run осталось активным, `DisablePayload` пуст. Это ожидаемый режим аудита, который предупреждает без автоматического отключения. Он не доказывает работу режима `EnforceBlock`.
- Microsoft Defender отдельно обнаружил **`Virus:DOS/EICAR_Test_File`**, ThreatID `2147519003`, и сообщил `ActionSuccess=true`; после теста `IsActive=false`.
- Вердикт Kaspersky для этой записи не получен: поля зоны и детекта пусты. Обнаружение Defender не выдаётся за собственный антивирусный вердикт Startup Monitor.
- Очистка подтвердила отсутствие собственного значения в активном Run и `StartupMonitorDisabled`, файла и временного каталога. История обнаружения сохранена.

Эта проверка подтверждает обработку настоящего изменения автозагрузки работающей службой при текущих настройках. Она не проверяет запуск EICAR, ETW-событие его процесса или защиту от произвольных настоящих вирусов. Отдельные автоматические и нативные проверки обратимого отключения описаны в [аудите восстановления](STARTUP_DISABLE_RESTORE_AUDIT.md).

Локальные доказательства: `out/release-verification-20261106-2.1.1/eicar-startup/eicar-startup-result.json`, `cleanup-verification.json` и проверочный скрипт `Invoke-EicarStartupProbe.ps1`. EICAR-файл в репозиторий и дистрибутив не включается.

Основания методики: [EICAR — официальный тестовый файл](https://www.eicar.org/download-anti-malware-testfile/), [Microsoft — безопасная проверка антивирусного обнаружения](https://learn.microsoft.com/en-us/defender-endpoint/validate-antimalware).
