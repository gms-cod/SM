# Контроль выпуска Startup Monitor 2.0.12

Версия содержит все [функциональные исправления повторного аудита](AUDIT_FIXES_v2.0.11_2026-11-02.md): согласование правил портов, достоверные результаты firewall, независимую от UI защиту, безопасный IPC, сохранение конкурентных изменений, реальную историю трафика, локализацию и восстановление при отказе развёртывания.

## Дополнительное исправление проверки WPF

В основном репозитории релизная проверка 2.0.11 выявила нестабильный тест `NetworkTimelineChartControl_SetDataPoints_HandlesNullAndEmptyGracefully`: отдельный STA-поток не завершил холодную инициализацию за десять секунд. Другие прогоны того же коммита прошли, но этот результат требовал устранения зависимости от отдельного потока.

Теперь обе группы настоящих WPF-тестов используют один `ICollectionFixture<NetworkRenderingTestHost>` и один STA-диспетчер с ресурсами приложения. Сценарии пустых и реальных данных сохранены; самостоятельный поток с `Join(10 секунд)` удалён. Полный прогон: **1406 пройдено, 0 ошибок, 0 пропусков**. Проверки файлового развёртывания: **5 пройдено**.

Существующие теги и установщик 2.0.11 не перезаписывались. Для исправленного набора исходников подготовлена новая уникальная версия 2.0.12.

## Прямые запуски и установка

- Напрямую запущены `SMon2/StartupMonitor.Service.exe --console` и `SMon2/StartupMonitor.UI.exe`.
- После штатного выхода UI служба продолжает отвечать через IPC; отдельная команда ShutdownService штатно завершает console-host.
- В установленной копии выход из UI сохраняет службу Running. Проверен путь SCM `"C:\Program Files\StartupMonitor\StartupMonitor.Service.exe"`.
- Свежие журналы обеих копий проверены: ошибок и исключений нет. Пропуск сканирования реестра из-за CPU-троттлинга во время компиляции установщика является ожидаемым ограничением нагрузки.
- Установщик проверяется реальным обновлением рабочей копии; пользовательская конфигурация сохраняется.

Рабочая копия пользователя обновляется в `C:\Program Files\StartupMonitor\`; UI запускается через интерактивную задачу планировщика. EXE и установщик подписаны Gms CodeWorks, локальная проверка Authenticode — Valid. Версии PE — **2.0.12.0**.

Файл: `StartupMonitorSetup-2.0.12.exe`.

SHA-256: `280baf9b252695017960030c8691ae3e0a87304c44e82fb681962dc1a9848a2d`.
