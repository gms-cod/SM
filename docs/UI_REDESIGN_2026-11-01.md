# Переработка сетевого экрана и навигации

Дата: 1 ноября 2026 года. Основа изменений: текущая версия исходников 2.0.8.

## Что изменено

| Область | Результат |
| --- | --- |
| Политика приложения | Вместо трёх не помещавшихся переключателей используется компактный список: «Разрешено», «Спрашивать», «Не разрешено». Все варианты доступны целиком. |
| Подтверждение изменения | Односторонняя привязка сохраняет фактическое значение до успешного ответа службы. Отмена блокировки, отказ и исключение возвращают прежний выбор. Во время запроса повторное изменение исключено. |
| Системные процессы | Вариант блокировки критического компонента отключён; подтверждение для защищённых процессов сохранено. |
| Таблица приложений | Имя получает гибкую ширину; срок действия показан под политикой; действия заменены компактными кнопками с подсказками. Полные пути сохранены. |
| Верхняя часть страницы | Компактная сводка состояния и профилей. Глобальные режимы и параметры уведомлений находятся в раскрываемом блоке «Параметры защиты». |
| Навигация сетевого экрана | «Приложения», «Соединения», «Защита портов», «Блокировки», «История», «Правила». Начальная вкладка — приложения. Внутренние идентификаторы вкладок сохранены. |
| Подсказки разделов | Каждая вкладка имеет понятный заголовок и короткое описание её назначения. |
| Поиск и фильтры | Поиск отделён от переносимых фильтров и кнопок, чтобы они не вытесняли друг друга на узкой странице. |
| Правила | Основные команды видимы сразу. Экспорт, импорт, наборы правил и специальные действия сгруппированы в «Дополнительные действия». |
| Соединения и график | Диапазоны графика и фильтры перенесены на независимые строки. Измерения и существующее поведение сбора сохранены. |
| Защита портов и история | Статус, фильтры и команды организованы последовательно; широкие неподвижные панели заменены переносимыми группами. |
| Темы | Используются существующие ресурсы Fluent и палитра приложения. Политика и таблица читаются в светлой и тёмной теме. |
| Локализация | Новые подписи и пояснения добавлены в RU/EN. Множества ключей обоих ресурсов согласованы. |
| Ресурсы | Новых таймеров и фоновых сетевых циклов не добавлено. Таблицы сохраняют виртуализацию. |

## Названия и порядок левого меню

Верхняя группа повседневной работы:

1. **Автозапуск** — прежний «Обзор».
2. **Процессы**.
3. **Сетевой экран**.

Группа «Анализ»:

4. **Загрузка Windows** — уточнено назначение прежней «Загрузки».
5. **Снимки** — прежние «Снимки системы»; речь о состояниях автозапуска.
6. **Изменения** — история изменений записей автозапуска.

Группа «Управление»:

7. **Чёрный список**.
8. **Удалённые**.
9. **Журнал** — прежние «Логи».

Внизу остаются **Настройки** и **Выход**. Для пунктов добавлены поясняющие подсказки. Центральная часть меню прокручивается при недостаточной высоте. Изменён визуальный порядок, а не стабильные идентификаторы страниц: ранее сохранённая вкладка продолжает открывать тот же раздел.

- UI собран без ошибок и предупреждений.
- Профильный набор настоящих WPF layout/render и поведенческих тестов: **20 пройдено, 0 ошибок, 0 пропусков**.
- Полный `dotnet test StartupMonitor.sln -p:ExcludePublishToSMon=true`: **1368 пройдено, 0 ошибок, 0 пропусков**.
- Проверены реальные размеры списка политики при ширине страницы 760 и 1040 DIP, все три состояния, запрет Block для критического процесса, отмена подтверждения и ожидание результата службы.
