# Спецификация 8 концептов редизайна рабочего пространства Startup Monitor

> Все 8 вариантов разработаны на основе реальной функциональности продукта (Автозагрузка, Процессы, Сетевой экран, Снимки системы, Защита портов, ИИ-рейтинг, Инструменты).  
> Все макеты сгенерированы в разрешении **1920x1080 (PNG)** и доступны для просмотра в папке `docs/images/designs/`.

---

## Вариант 1: «Cyber Command Center» (EDR HUD)
- **Изображение**: [`docs/images/designs/variant_1_cyber_command_center.png`](images/designs/variant_1_cyber_command_center.png)
- **Целевая аудитория**: Продвинутые пользователи, энтузиасты кибербезопасности, геймеры.
- **Цветовая палитра**:
  - Фоны: глубокий угольный `#080B10`, карточки `#0F172A`, разделители `#1E293B`.
  - Неоновые акценты: циан `#00F0FF`, изумрудный `#10B981`, тревожный кармин `#EF4444`.
- **Компоновка**:
  - *Верхний HUD телеметрии*: осциллографы ядер CPU, памяти, активных сетевых сокетов, статуса защиты ARMED 24/7.
  - *Центральная тактическая панель*: список процессов с цветными индикаторами подлинности подписей, статуса Kaspersky OpenTIP и ИИ-рейтинга.
  - *Правый командный центр*: тумблеры боевых режимов (Eco-Sensing 0% CPU, Port Defender, Whitelist/Blacklist) и консоль событий ядра.

## Вариант 2: «Security Matrix Board» (MITRE ATT&CK)
- **Изображение**: [`docs/images/designs/variant_2_security_matrix.png`](images/designs/variant_2_security_matrix.png)
- **Целевая аудитория**: Системные администраторы, SOC-аналитики, специалисты ИБ.
- **Цветовая палитра**: темно-серый GitHub Dark `#0D1117`, панели `#161B22`, цветные рамки риска.
- **Компоновка**:
  - Четыре вертикальные колонки по степеням риска:
    1. *Critical Risks* (Недоверенные скрипты, LOLBAS-утилиты, Base64).
    2. *Suspicious / Audit* (Без подписи, запуск из Temp, отложенный запуск).
    3. *Trusted Services* (Системные службы Windows и драйверы ядра).
    4. *Verified User Apps* (Проверенные пользовательские программы с подписью).
  - Карточки содержат теги матрицы MITRE ATT&CK (`T1059.001`, `T1547.001`) и кнопки быстрой изоляции.

## Вариант 4: «Modular Tiles Grid» (Сетка виджетов)
- **Изображение**: [`docs/images/designs/variant_4_modular_tiles_grid.png`](images/designs/variant_4_modular_tiles_grid.png)
- **Целевая аудитория**: Пользователи с большими мониторами (2K / 4K), любящие настраивать рабочее пространство под себя.
- **Цветовая палитра**: Slate `#0F172A`, плитки `#1E293B`, цветные рамки блоков.
- **Компоновка**:
  - Сетка 3x2 перетаскиваемых модульных виджетов:
    * Виджет 1: Сводка автозагрузки (Реестр, Задачи, Службы).
    * Виджет 2: Сетевой радар (активные TCP/UDP сокеты с флагами стран).
    * Виджет 3: Топ-3 процесса по потреблению ресурсов.
    * Виджет 4: Port Defender (RDP 3389, SSH 22, авто-бан атак).
    * Виджет 5: Снимки «Было — Стало» со счетчиком дельт.
    * Виджет 6: Набор утилит (File Locksmith, Keep-Awake, Junk Cleaner).

- **Изображение**: [`docs/images/designs/variant_5_split_dual_pane_pro.png`](images/designs/variant_5_split_dual_pane_pro.png)
- **Целевая аудитория**: Инженеры техподдержки, разработчики, опытные пользователи (стиль Sysinternals / Process Hacker).

- **Компоновка**:
  - Экран разделен на две части с перемещаемым сплиттером:
    * *Левая панель (45%)*: иерархическое дерево процессов (родители → дочерние) с мгновенным поиском и счетчиками ядер.
    * *Правая панель (55%)*: 4 вкладки инспектора выбранного процесса: «Сетевые сокеты», «Модули и DLL», «Безопасность ИИ», «Снимки и история».

## Вариант 7: «Process-Centric Graph Hub» (Интерактивная топология)
- **Изображение**: [`docs/images/designs/variant_7_process_graph_hub.png`](images/designs/variant_7_process_graph_hub.png)
- **Целевая аудитория**: Визуальные аналитики, презентационные дашборды.
- **Цветовая палитра**: `#05070D`, узлы графа `#0F172A`, неоновые связи `#38BDF8`.
- **Компоновка**:
  - *Центр*: интерактивный граф связей. Корневой узел ядра Windows -> Дочерние деревья процессов -> Сетевые сокеты -> Внешние облачные узлы.
  - Узлы подсвечены цветами репутации (зеленый = доверенный, желтый = отложенный, красный = угроза).
  - *Справа*: боковая карточка свойств выбранного узла графа.
