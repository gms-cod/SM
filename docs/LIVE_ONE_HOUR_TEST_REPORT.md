## 6. Найденные аномалии и риски

1. **Idle CPU ≈ 0.8%, а не 0%** — драйвер `WmiScan`/`Wmi.ScanSubscriptions` каждые 30 с.
2. **Высокая вариативность сканов** — `ScanRegistry` ×59, `ScanServices` ×5 → нестабильная латентность UI-обновлений.
3. **`KasperskyScan` фиктивный** — сетевая проверка возвращается за ~15 мс (кэш/no-op).
4. **`JsonDataStoreLoad` ×365/5 мин** — потенциальный N+1 при росте данных.
5. **Нет метрик Named Pipe/IPC и UI-процесса** — выборка содержит только `StartupMonitor.Service`.
6. **Реестр/сервисы без кэша между циклами** — тёплый прогон в 5–60× быстрее (O2 vs O1/O3).
