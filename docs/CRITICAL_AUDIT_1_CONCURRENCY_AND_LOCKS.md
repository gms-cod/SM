## 1️⃣  PipeServer / EventPipeServer  –  **Паттерн безопасного обмена данными между потоками**

```csharp
// ПРИМЕР ПЛОХОЙ ПРАКТИКИ
lock (this)
{
    // ОПАСНО: длительная операция внутри блокировки
    foreach (var sub in _subscribers)
        sub.PostEvent(data);
}

// ПРИМЕР ХОРОШОЙ ПРАКТИКИ
// 1) Захватите только состояние, необходимое для списка рассылки
List<IUISubscriber> snapshot;
lock (_subscribers) // короткая критическая секция
{
    snapshot = _subscribers.ToList(); // создаем копию
}

// 2) Запланируйте рассылку ОТСЮДА блокировки
_ = Task.Run(() => // используйте пул потоков, НЕ UI-поток
{
    foreach (var sub in snapshot)
    {
        try { sub.PostEvent(data); }
        catch { /* отложите повторную попытку или удалите подписчика */ }
    }
});
```
