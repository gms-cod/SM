## Дополнительные найденные проблемы

В одном прогоне CI 2.0.12 чистый профиль Windows не содержал ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Три теста ошибочно предполагали его наличие, подготавливая только RunOnce. Теперь каждый тест явно создаёт нужный ключ, использует уникальное реальное значение, проверяет удаление или восстановление и данные payload, очищает значение в `finally`. Зависимость от очередности других тестов исключена. Прежний тест восстановления оставлял фиксированное значение TestValue; новая реализация его не создаёт.

Реальное развёртывание выявило промежуток между статусом SCM Stopped и освобождением EXE процессом .NET. Неудачная попытка обновления корректно откатилась. Процедура теперь получает актуальный PID, ожидает фактического завершения процесса после остановки SCM и освобождает дескрипторы. При таймауте замена отменяется. Исправленная процедура успешно обновила обе копии.

Опубликованные версии 2.0.11 и 2.0.12 не изменялись. Для дополнительных исправлений повышена уникальная версия до 2.0.13.
