# Startup Monitor 2.2.2

Проверка / Validation: Release build без предупреждений; 1833 теста пройдены, 0 ошибок и пропусков.

## Русский

- Проверка открытого сетевого уведомления больше не ждёт полного обхода правил брандмауэра. Если сканирование задерживает принятие решения, служба сообщает об этом и допускает безопасный повтор; подтверждённое решение повторно не применяется.
- Исправлена регистрация автозапуска интерфейса для системных учётных записей. После подтверждения пользовательской задачи удаляется только точно опознанная ошибочная задача LocalSystem; посторонние задачи сохраняются.
- IPv6-адреса с портами в уведомлениях отображаются в квадратных скобках.

## English

- Checking an open network alert no longer waits for a full firewall rule scan. If scanning delays a decision, the service reports that it is busy and allows a safe retry; a confirmed operation is not applied twice.
- UI autostart no longer registers tasks for built-in service accounts. After the user's task is confirmed, only the precisely identified erroneous LocalSystem task is removed; unrelated tasks are preserved.
- IPv6 addresses with ports in notifications are displayed in brackets.
