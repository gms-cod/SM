# Startup Monitor 2.2.1

Release date / Дата выпуска: 2026-11-12.

Validation / Проверка: Release test suite 1813 passed, 0 failed, 0 skipped. Incoming TCP ETW was checked with isolated IPv4 and IPv6 loopback connections and three observer start/stop cycles; external traffic and the full UI notification path were not part of that probe.

## English

- Startup entry operations compensate for a failure to persist an enable or disable operation; an unsuccessful compensation is reported explicitly.
- Automatic protection reports a failure when an entry could not be disabled instead of claiming success.
- The ETW readers release their consumers after processing ends, including when stopping the incoming TCP observer takes longer than expected.
- The system information and incoming TCP documentation describes the actual snapshot, notification limits and coverage. See the corrected [2.2.0 notes](v2.2.0.md) for the earlier features.

## Русский

- При ошибке сохранения включения или отключения автозапуска выполняется восстановление прежнего состояния; если восстановить его не удалось, об этом сообщается отдельно.
- Автоматическая защита сообщает об отказе отключения записи вместо сообщения об успешной блокировке.
- Читатели ETW освобождают ресурсы после завершения обработки, в том числе при затянувшейся остановке наблюдателя входящего TCP.
- Описания сведений о системе и входящего TCP уточнены: указаны режим снимка, предел уведомлений и границы наблюдения. Возможности предыдущего выпуска описаны в исправленных [заметках 2.2.0](v2.2.0.md).
