# Startup Monitor 2.0.11

Исправлены подтверждённые дефекты повторного аудита: некорректные IPC-кадры больше не оставляют повреждённое соединение, подписки метрик освобождаются при отключении клиента, ошибки Windows Firewall не объявляются успешным разбаном, повторный бан восстанавливает отключённое управляемое правило.

Управление защищаемыми портами согласованно изменяет порты и индивидуальные правила. Удалённый порт больше не возвращается после нормализации; перенос сохраняет настройки. Ошибка записи конфигурации оставляет прежнее состояние. Закрытие UI завершает интерфейс и сохраняет работу системной защиты.

Исправлены повторные и смешанные сохранения настроек, порядок событий паузы, жизненный цикл WMI и обработка штатной отмены Kaspersky. История трафика хранит реальные интервалы покрытия, сохраняет пропуски и ограничивает размер файла. Непригодный файл истории не мешает запуску службы.

Завершена RU/EN-локализация истории сети и Port Defender, включая открытые диалоги и подписи графика. Устранены обращения фильтра истории к незаданным XAML-контролам.

Обновление установленной копии выполняется с резервированием, проверкой SHA-256 и откатом. Право остановки системной службы через SCM доступно администраторам и системе.

Проверка: **1406 тестов Release и 5 тестов развёртывания, 0 ошибок**. Выполнены прямые запуски Service/UI, штатный выход, проверка продолжения защиты без UI и инспекция свежих журналов. Рабочая копия в `C:\Program Files\StartupMonitor\` обновлена. Подробности: [отчёт исправлений](../AUDIT_FIXES_v2.0.11_2026-11-02.md).
