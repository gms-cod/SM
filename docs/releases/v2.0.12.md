# Startup Monitor 2.0.12

Включены исправления полного повторного аудита: управление портами и правилами Defender, достоверные результаты ban/unban Windows Firewall, освобождение подписок при разрыве IPC, защита от повреждённых кадров, сохранение конкурентных изменений, реальные интервалы истории трафика и корректное восстановление после ошибки обновления.

Выход из интерфейса сохраняет работу системной защиты. Закрытие главного окна завершает процесс UI. Исправлены ранние XAML-события фильтра истории, порядок событий паузы, завершение WMI и диагностика штатной отмены Kaspersky. История сети и Port Defender поддерживают живое переключение RU/EN.

Дополнительно устранена нестабильность проверки графика на CI: тесты WPF используют общий STA-диспетчер и ресурсы приложения вместо отдельного потока с десятисекундным ожиданием. **1406 тестов Release и 5 проверок развёртывания прошли без ошибок.**

Проверены реальные Service/UI, продолжение защиты после закрытия окна, журналы и обновление рабочей копии в `C:\Program Files\StartupMonitor\`. [Контроль выпуска](../AUDIT_RELEASE_v2.0.12_2026-11-02.md).

Бинарники и установщик подписаны **Gms CodeWorks**. GitHub Actions проверяет и публикует подготовленный локальный установщик без повторной сборки. Существующие выпуски и теги не перезаписываются.
