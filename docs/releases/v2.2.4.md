# Startup Monitor 2.2.4

Release date / Дата выпуска: 2026-11-12.

Validation / Проверка: Release build без предупреждений; 1839 тестов пройдены, 0 ошибок и пропусков.

## Русский

- Исправлено открытие окна расширенной информации о компьютере: устранены ошибки привязки `Run.Text` на свойствах локализации `LocalizationService`, элементы переведены на каноничную двухколоночную сетку `Grid` с `TextBlock`.
- Добавлена полноценная поддержка отображения расширенных аппаратных сведений: производитель и модель компьютера, модель системной платы, версия и дата выпуска BIOS, системный каталог Windows.
- Добавлен ключ запуска командной строки `--system-info` для прямого вывода окна информации об устройстве.
- Добавлен комплексный набор модульных тестов `SystemInfoWindowTests` (проверка парсинга XAML, рендеринга визуального дерева, сбора параметров и формирования структурированного отчёта `ToReportString`).

## English

- Fixed the opening of the expanded computer information window: resolved `Run.Text` binding exceptions on read-only `LocalizationService` properties by migrating to canonical two-column `Grid` layouts with `TextBlock`.
- Full display support added for extended hardware attributes: computer manufacturer and model, motherboard model, BIOS version and release date, and Windows installation directory.
- Added `--system-info` command-line startup switch to directly display the system hardware diagnostics dialog.
- Added comprehensive unit test suite `SystemInfoWindowTests` covering XAML loading, visual tree rendering, hardware collection, and structured `ToReportString` generation.
