# Startup Monitor 2.0.13

Выпуск включает все исправления повторного аудита: согласование портов и правил Port Defender, достоверные результаты Windows Firewall, независимую от UI защиту, безопасный IPC, сохранение конкурентных изменений, реальную историю трафика и локализацию RU/EN.

Дополнительно исправлены подготовка реестра в чистом профиле Windows и обновление установленной копии: после остановки SCM процедура ожидает фактическое завершение процесса службы перед заменой EXE. При отказе выполняется проверяемый откат. WPF-тесты используют общий STA-диспетчер.

Проверки: **1406 тестов Release и 5 проверок развёртывания пройдены без ошибок и пропусков**. Через настоящий UI-клиент и работающую службу подтверждены добавление, сохранение и удаление тестового порта; исходная конфигурация восстановлена. Проверены реальные Service/UI, продолжение защиты после закрытия окна, свежие журналы и установленная копия `C:\Program Files\StartupMonitor\`.

EXE и установщик подписаны **Gms CodeWorks**. GitHub Actions публикует тот же проверенный локальный установщик. Старые теги и файлы не перезаписываются. [Подробности проверки](../AUDIT_RELEASE_v2.0.13_2026-11-02.md).
