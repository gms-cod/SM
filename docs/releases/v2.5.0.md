## Русский

- **Непрерывный анализ активных процессов на лету (Continuous Real-Time Process Threat Scanning)**:
  - Фоновый координатор службы `ProcessThreatScanCoordinator` непрерывно проверяет активные процессы Windows на лету каждые 15 секунд, а также мгновенно ставит в очередь вновь запускаемые процессы при получении их метаданных в `ProcessMetadataEnricher`.
  - Автоматическая проверка контрольных сумм SHA-256 через Kaspersky OpenTIP (детекты, распределение по зонам Green / Yellow / Red) и поведенческий ИИ-анализ (AI Risk Score 0..100 с вердиктом и подробным объяснением).
  - Мгновенное обогащение из кэша метаданных `CachedProcessMetadata` без блокировки интерфейса и задержек.
- **Динамическая цветовая индикация пульса безопасности (Pulse Color Badges)**:
  - Иконка пульса (`IconPulse`) перед именем каждого процесса в «Диспетчере процессов» динамически окрашивается в соответствии с комплексным рейтингом угроз:
    - `#DC2626` (тёмно-красный / Высокая угроза): Детект Kaspersky (Red zone), AI Risk Score >= 75 или высокий уровень угрозы CLI.
    - `#F59E0B` (оранжево-жёлтый / Повышенный риск): Предупреждение Kaspersky (Yellow zone), AI Risk Score >= 45 или умеренная угроза CLI.
    - `#EAB308` (жёлтый / Незначительный риск): AI Risk Score >= 20 или низкий уровень подозрительности CLI.
    - `#10B981` (изумрудно-зелёный / Безопасен): Проверенный процесс по базам Kaspersky (Green zone), безопасный вердикт ИИ (< 20) либо доверенный системный процесс.
    - `#00D2D3` (бирюзовый / В очереди): Процесс поставлен в очередь непрерывного анализа на лету.
  - Информативный тултип с подробным разложением параметров безопасности при наведении на иконку пульса.
- **Окно детальных свойств процесса (Process Detail Window)**:
  - Открытие по двойному клику на строку любого процесса в списке или через контекстное меню («Свойства процесса...»).
  - Карточка комплексного рейтинга безопасности (ИИ + Kaspersky OpenTIP + CLI-эвристика).
  - Карточка метаданных исполняемого файла: путь, SHA-256 с кнопкой быстрого копирования, полная командная строка CLI аргументов, статус подписи Authenticode и родительский PID.
  - Карточка системных ресурсов в реальном времени: ЦП, RAM, Диск, Сеть.
  - Быстрые действия: просмотр сетевых подключений процесса, список загруженных модулей и DLL, завершение процесса.
- **Защита критических процессов (System Safeguard & Anti-Mimicry)**:

  - Защита системных процессов от случайного завершения с предупреждением пользователя.

## English

- **Continuous Real-Time Process Threat Scanning**:
  - The background service coordinator `ProcessThreatScanCoordinator` continuously evaluates active Windows processes on the fly every 15 seconds and automatically enqueues freshly launched processes upon metadata capture in `ProcessMetadataEnricher`.
  - Automated SHA-256 hash evaluation against Kaspersky OpenTIP (detection verdicts, Green/Yellow/Red zone classification) combined with heuristic AI behavioral analysis (AI Risk Score 0..100 with structured verdict and explanation).
  - Instant metadata enrichment via `CachedProcessMetadata` ensuring non-blocking, fluid UI responsiveness.
- **Dynamic Security Pulse Color Badges**:
  - The activity pulse icon (`IconPulse`) preceding each process name in the Process Manager dynamically shifts color based on composite safety evaluation:
    - `#DC2626` (Dark Red / Critical Risk): Kaspersky Red zone detection, AI Risk Score >= 75, or High CLI heuristic threat.
    - `#F59E0B` (Amber Orange / Elevated Risk): Kaspersky Yellow zone warning, AI Risk Score >= 45, or Medium CLI threat.
    - `#EAB308` (Yellow / Moderate Risk): AI Risk Score >= 20 or Low CLI threat.
    - `#10B981` (Emerald Green / Clean): Verified clean via Kaspersky OpenTIP Green zone, low AI risk (< 20), or verified trusted system process.
    - `#00D2D3` (Cyan / Queued): Process queued for real-time background analysis.
  - Rich interactive tooltip detailing the exact score breakdown on pulse hover.
- **Comprehensive Process Properties Dialog (Process Detail Window)**:
  - Opened via double-clicking any process row or via the context menu ("Process Properties...").
  - Unified Security Rating card (AI + Kaspersky OpenTIP + CLI heuristics).
  - Metadata & Executable card: file path, SHA-256 checksum with one-click copy, complete CLI arguments, Authenticode signature status, and parent PID.
  - Real-time resource consumption metrics: CPU, RAM, Disk, and Network bandwidth.
  - Direct action triggers: inspect active network sockets, view loaded modules/DLLs, and terminate process.
- **Critical Process Safeguards & Anti-Mimicry Protection**:
  - Anti-mimicry verification: strict canonical path checks (`C:\Windows\System32`) preventing malicious binaries masquerading as critical OS components.
  - System process safeguard preventing unintended termination of vital Windows services.
- **Reliability & Quality Assurance**:
  - Complete xUnit automated test suite: 1,944 tests passing (100% passing).
  - Strict compliance with Zero-Crash and Zero-Stub engineering standards.
