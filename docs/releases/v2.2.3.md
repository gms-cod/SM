# Startup Monitor 2.2.3

Проверка / Validation: Release build без предупреждений; 1836 тестов пройдено, 0 ошибок и пропусков.

## Русский

Улучшен контраст текста стандартных акцентных кнопок: цвет выбирается по фактическому фону и обновляется при изменении акцента Windows. Исправления сетевых уведомлений и автозапуска описаны в [версии 2.2.2](v2.2.2.md).

## English

Improved text contrast on standard accent buttons: the foreground follows the actual background and updates when the Windows accent changes. Firewall alert and autostart fixes are described in [version 2.2.2](v2.2.2.md).
