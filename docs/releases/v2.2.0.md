# Startup Monitor 2.2.0

Release date / Дата выпуска: 2026-11-12. Branch / Ветка: `main`.

Validation / Проверка: full Release test suite **1809 passed, 0 failed, 0 skipped**. Native Windows verification confirmed temporary WFP blocking and restoration over IPv4 and IPv6, permanent COM In/Out pair readback/removal, hardware metrics telemetry, and compensation after a controlled persistence failure.

## English

This release introduces an extended System Information and Hardware Metrics module, incoming TCP socket telemetry, and architectural reliability enhancements across startup entry management and AI rating context fingerprinting.

- **System Information & Hardware Diagnostics**:
  - Added detailed hardware telemetry window (`SystemInfoWindow`) displaying motherboard vendor, BIOS version, CPU specifications, GPU adapters, RAM topology, and OS build with system uptime.
  - Real-time computer metrics collection with IPC transfer via `PipeMessageTypes.GetComputerInfo`.
- **Incoming TCP Observer & Firewall Telemetry**:
  - Implemented `IncomingTcpObserver` for passive inspection and telemetry of incoming TCP connections.
  - Integrated incoming TCP observations with network traffic history and threat scoring.
- **Robust Startup Entry Disable & Restore Lifecycle**:
  - Comprehensive transactional compensation for startup entry disabling and restoration (`AutomaticStartupDisableRestore`).
  - Strict fallback handling on registry and file permission errors (`DisableEntryFailure`).
- **AI Rating Context Fingerprinting & Graceful Cancellation**:
  - Canonical SHA-256 fingerprinting of startup entry state via `StartupRatingContext` ensuring AI ratings cache validity.
  - Deterministic shutdown cancellation (`AiShutdownCancellation`), terminating in-flight HTTP requests immediately when the service stops.

## Русский

Выпуск представляет расширенный модуль сведений о системе и оборудовании, телеметрию входящих TCP-соединений, а также архитектурные улучшения надежности управления элементами автозапуска и кэширования оценок ИИ.

- **Сведения о системе и аппаратная диагностика**:
  - Добавлено окно детальной аппаратной телеметрии (`SystemInfoWindow`): материнская плата, версия BIOS, детальные характеристики CPU, видеоадаптеры, топология оперативной памяти, точная сборка Windows и время непрерывной работы (Uptime).
  - Сбор системных метрик в реальном времени с передачей по защищённому каналу IPC через `PipeMessageTypes.GetComputerInfo`.
- **Наблюдатель входящих TCP-соединений**:
  - Реализован компонент `IncomingTcpObserver` для пассивного анализа входящих TCP-подключений.
  - Интеграция наблюдений входящего трафика в общую историю сетевых подключений.
- **Транзакционное отключение и восстановление автозапуска**:
  - Комплексная компенсация при сбоях изменения состояния записей автозапуска (`AutomaticStartupDisableRestore`).
  - Строгая обработка и локализация ошибок доступа к реестру и файловой системе (`DisableEntryFailure`).
- **Отпечатки контекста ИИ (Context Fingerprinting) и отмена при остановке**:
  - Канонический расчет отпечатков SHA-256 через `StartupRatingContext`, исключающий устаревание кэша оценок при изменении параметров записи.
  - Детерминированная отмена фоновых запросов ИИ при остановке службы (`AiShutdownCancellation`) без ожидания сетевых таймаутов.
