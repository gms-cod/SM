# Startup Monitor 2.2.0

Release date / Дата выпуска: 2026-11-12. Branch / Ветка: `main`.

## English

- **System information:** The computer information window includes the device model, motherboard, BIOS version and date, Windows directory and build, alongside processor name, logical processor count, memory usage, fixed drives and uptime. Information is collected locally in a background task when the window is opened or refreshed; unavailable fields can be empty. This is a snapshot, not continuous hardware monitoring.
- **Incoming TCP notifications:** An optional, disabled-by-default observer reports accepted external TCP connections through notifications. It does not block traffic, add these observations to connection history or score threats. Private/local addresses are filtered, notifications are globally limited to one per three seconds, and ETW or notification limits can cause events to be missed. UDP and QUIC are outside its scope.
- **Startup entries:** Disabling and restoring entries handles system failures more explicitly, preserves registry backups on conflicting values and reports failures rather than presenting them as successful operations. If removing a blacklist rule succeeds but enabling the entry fails, the interface reports the partial result.
- **AI ratings:** Automatic ratings are tied to a fingerprint of the startup context. A response is only saved if that context still matches and a user rating has not replaced it. In-flight requests and retry delays support cancellation when the service stops.

## Русский

- **Сведения о системе:** окно показывает модель компьютера, системную плату, версию и дату BIOS, каталог и сборку Windows, а также процессор, число логических процессоров, использование памяти, постоянные диски и время работы. Сведения собираются локально в фоновом потоке при открытии или обновлении окна; недоступные поля могут быть пустыми. Это снимок состояния, а не непрерывный мониторинг оборудования.
- **Уведомления о входящих TCP:** необязательный наблюдатель, выключенный по умолчанию, сообщает о принятых внешних TCP-соединениях. Он не блокирует трафик, не добавляет эти наблюдения в историю соединений и не оценивает угрозы. Частные и локальные адреса исключаются, общий предел — одно уведомление за три секунды; события могут теряться из-за ограничений ETW или уведомлений. UDP и QUIC не охватываются.
- **Записи автозапуска:** при отключении и восстановлении точнее обрабатываются системные ошибки, резервные значения реестра сохраняются при конфликте, а отказ не показывается как успешное действие. Если удаление правила чёрного списка выполнено, но включение записи не удалось, интерфейс сообщает о частичном результате.
- **Оценки ИИ:** автоматическая оценка связана с отпечатком контекста записи автозапуска. Ответ сохраняется только при неизменном контексте и отсутствии новой пользовательской оценки. Запросы и ожидание повторов поддерживают отмену при остановке службы.
