# Startup Monitor 2.1.1

Исправлена обработка решений во всплывающем окне брандмауэра. Окно закрывается после подтверждения службы; при ошибке остаётся открытым с возможностью повторить выбор. Повторный запрос идемпотентен, а правила привязаны к полному пути приложения. Временное разрешение и запрет реально применяются через динамические WFP-фильтры с ограниченным сроком действия и автоматической очисткой при завершении службы. Ограничения внешних блокирующих правил объясняются в интерфейсе.

Завершена функциональная интеграция ETW: события процессов, начальная и периодическая сверка, защита от повторного использования PID, отдельное обогащение метаданных и событийное применение чёрного списка. Потери и ошибки источника сохраняют резервную проверку. Защищённые процессы Windows проверяются с минимально необходимыми правами; право завершения запрашивается только после совпадения с правилом.

Автоматическая блокировка автозагрузки теперь **отключает запись с сохранением возможности включить её обратно**. Ручное удаление сохраняет отдельную резервную копию. Восстановление задач сохраняет исходные principal и тип входа, а watcher распознаёт явное восстановление пользователя. Исправлены безопасные повторы восстановления и сохранение типизированных значений реестра. Найдены причины отказа восстановления Antigravity; реальная пользовательская задача при проверке не включалась.

Возвращён крестик в заголовке: он скрывает окно в трей. Пункт «Выход» завершает интерфейс, оставляя системную службу работающей.

Подробности: [брандмауэр](../FIREWALL_ALERT_AUDIT.md), [ETW](../ETW_IMPLEMENTATION_AUDIT.md), [отключение и восстановление](../STARTUP_DISABLE_RESTORE_AUDIT.md).

Сайт проекта: [sm.monidom.ru:8443](https://sm.monidom.ru:8443/).

Установщик подписывается самоподписанным сертификатом разработчика Startup Monitor. Локальный статус `Valid` не означает публичного доверия сертификату на другом компьютере и не гарантирует отсутствия предупреждения SmartScreen. Для проверки целостности публикуется SHA-256. GitHub Actions публикует тот же локально проверенный установщик.

Многосуточный нагрузочный прогон ETW, сравнительные CPU/p95/p99 и работа на разных физических мониторах требуют отдельного этапа тестирования; этот выпуск не заявляет прохождения этих измерений.
