## Русский

- **Центр защиты от шифровальщиков (Anti-Ransomware Shield)**:
  - Реализована комплексная превентивная защита от программ-вымогателей по Плану Б.
  - **Детектор деструктивных CLI**: мгновенный статический перехват команд нейтрализации резервных копий и точек восстановления (`vssadmin delete shadows`, `wmic shadowcopy delete`, `wbadmin delete catalog`, `bcdedit recoveryenabled no`, `wevtutil cl security`).
  - **Атомарная заморозка процессов (`ProcessFreezer`)**: приостановка выполнения атакующего процесса за < 1 мс через нативный вызов `ntdll!NtSuspendProcess` с обязательной валидацией `CreationTime` против PID Reuse.
  - **Сетевая изоляция через WFP (`WindowsFirewallService`)**: мгновенная изоляция зараженного процесса на уровне драйвера Windows Filtering Platform для предотвращения утечки ключей шифрования на C2-сервер злоумышленников.
  - **Сервис лексикографических ловушек (`CanaryTrapService`)**: размещение приманок с валидными magic-bytes (`!000_SecurityCanary.docx`, `!00_VaultArchive.xlsx`, `#00_FinancialAudit.pdf`) в критических каталогах пользователя с мониторингом модификаций через `FileSystemWatcher` / IOCP.
  - **Безаллокационный калькулятор энтропии (`ShannonEntropyCalculator`)**: вычисление информационной энтропии Шеннона со `stackalloc` (0 байт в GC) и предвычисленной таблицей `log2`.
  - **Пофайловое восстановление из VSS (`VssVolumeShadowRestorer`)**: автоматический откат зашифрованных или поврежденных файлов из теневых копий томов.
- **Графический интерфейс Fluent Design Windows 11**:
  - Добавлена новая выделенная вкладка «Защита от шифровальщиков» (`NavItemRansomware`, Tag 10) в боковом меню.
  - 4 стеклянные карточки метрик реального времени (Статус защиты, Активные ловушки, Предотвращенные атаки, Точки восстановления VSS).
  - Управление ключевыми компонентами защиты и ручное создание теневых копий VSS.
  - Интерактивный журнал зафиксированных инцидентов с детализацией процесса, причины и статуса.
  - Полная двуязычная локализация (русский и английский языки).
- **Надежность и качество**:
  - Комплексный пакет модульных тестов xUnit: `ShannonEntropyCalculatorTests` (7 тестов) и `RansomwareCliDetectorTests` (27 тестов).
  - 100% прохождение всех 1936 модульных тестов решения.

## English

- **Anti-Ransomware Shield Center**:
  - Implemented comprehensive proactive ransomware protection according to Plan B.
  - **Destructive CLI Detection**: instant static interception of backup/VSS tampering commands (`vssadmin delete shadows`, `wmic shadowcopy delete`, `wbadmin delete catalog`, `bcdedit recoveryenabled no`, `wevtutil cl security`).
  - **Atomic Process Freezing (`ProcessFreezer`)**: sub-millisecond process suspension via native `ntdll!NtSuspendProcess` with mandatory `CreationTime` validation against PID reuse attacks.
  - **WFP Network Quarantine (`WindowsFirewallService`)**: kernel-level network isolation via Windows Filtering Platform to sever outbound C2 encryption key exfiltration.
  - **Lexicographical Canary Traps (`CanaryTrapService`)**: strategically deployed decoy files with valid magic-bytes headers (`!000_SecurityCanary.docx`, `!00_VaultArchive.xlsx`, `#00_FinancialAudit.pdf`) monitored via IOCP-backed `FileSystemWatcher`.
  - **Zero-Allocation Shannon Entropy (`ShannonEntropyCalculator`)**: stackalloc-based Shannon entropy analysis (0 bytes GC pressure) with a 64K precomputed `log2` lookup table.
  - **Granular VSS Rollback (`VssVolumeShadowRestorer`)**: automated file-by-file restoration of affected files directly from Volume Shadow Copies.
- **Windows 11 Fluent Design Interface**:
  - Dedicated "Anti-Ransomware Shield" navigation tab (`NavItemRansomware`, Tag 10) integrated into the sidebar.
  - 4 glassmorphic real-time metric cards (Shield Status, Active Canary Traps, Prevented Attacks, VSS Snapshots).
  - Granular security toggles and on-demand VSS snapshot creation.
  - Detailed forensic incident log tracking timestamps, processes, triggers, and mitigation actions.
  - Complete dual-language localization (Russian and English).
- **Reliability & Quality Assurance**:
  - Comprehensive xUnit test suite: `ShannonEntropyCalculatorTests` (7 tests) and `RansomwareCliDetectorTests` (27 tests).
  - 100% passing across all 1,936 automated unit tests.
